My journey of learning information technology began at the age of 12 when I did a web search asking how websites worked, and began working on my own Javascript animations and video games using P5.js. Although simplistic, those projects lead to learning core programming concepts such as the math required to handle vectors, positions, velocity and acceleration as well as basic programming concepts such as arrays and nested loops. Eventually it led to me learning web-based protocols such as HTTP and Web Sockets that allowed me to start working on servers with state and real time feedback. Through middle school and high school I explored more advanced programming concepts such as OOP and basic memory management with languages such as Java and Rust with most of my Java experince coming from modding video games. Soon enough I would take the Computer Studies courses offered at Three Oaks Senior High where we covered web development, python scripts and basic arduino circuitry. I'd later apply to Holland College’s CIS program covering web development, databases, network communications, operating systems, security principles, and application development in Java and C#. Through my time at Holland College I would start networking with new people, make friends and start to take on new projects and opportunities.
